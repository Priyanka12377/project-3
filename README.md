# Team Task Manager

Full-stack web app for team project and task management with role-based access.

## Features
- User authentication (Signup/Login)
- Role-based access: Admin (create projects), Member
- Project management with teams
- Task creation, assignment, status tracking (pending/in-progress/completed)
- Dashboard with stats and overdue tasks
- REST APIs, MongoDB, React frontend

## Tech Stack
- Backend: Node.js, Express, MongoDB, JWT
- Frontend: React, Vite, Tailwind CSS, Axios
- Deployment: Railway

## Local Setup
1. MongoDB local or Atlas
2. Backend: `cd backend && npm install && npm run dev`
3. Frontend: `cd frontend && npm install && npm run dev`

## API Endpoints
- POST /api/auth/signup, /login
- GET/POST /api/projects (admin)
- GET/POST /api/tasks
